# Backend

- `src/roll_qr_scale`: HTTP API, nhận diện Gemini/local, SQLite và đồng bộ.
- `supabase`: migrations và Edge Functions.
- `supabase_schema.sql`: schema gộp dùng khi chạy qua SQL Editor.
- `requirements-render.txt`: dependency tối thiểu cho Render.

Render chạy package từ `backend/src` và phục vụ giao diện trong `frontend`.
